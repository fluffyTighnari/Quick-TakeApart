# Quick-TakeApart

把一个陌生代码库，拆成能一口气读完的小段。

你不需要先把整个项目读完。它先把这个项目压成一条主流程，再据此排出一条阅读路径，最后把每一段拆成「左边看路线、中间看代码、右边看讲解」的切片。

## 它解决的几种情况

- 接手一个几万行的项目，不知道从哪个文件开始读；
- 知道入口在哪，但看不出主流程和平行支线的关系；
- 单个函数看得懂，说不清它在整条链路上到底承担什么；
- 想改一处代码，不确定谁会受影响。

## 三个阶段

### 1. 逻辑骨架

只保留「主流程」与「平行支撑」两层，不把模块全部摊开。每个节点点开就能看到它在哪、负责什么、和谁相连、下一步该读哪里。讲解生成一次后冻结在骨架里，刷新页面不会丢重来。

### 2. 学习计划

把骨架节点排成一条有顺序的阅读路径，每一步引用一个切片，可以增删、调序、分组。计划对话可以直接提要求，比如“先讲错误处理”，它会重排步骤。

### 3. 切片阅读

左栏是阅读路线（原问题、视图、起止位置），中栏是真实代码，右栏是讲解与批注，需要时挂图表。来自骨架节点的切片直接复用骨架里的讲解，不会出现第二套说法。

## 阅读时能做什么

- **Ctrl + 点击** 函数或变量：跳到定义或引用列表。语言关键字、`self`、字面量不响应，避免满屏都可点。
- **引用追踪**：查“谁调用了它”“它又调用了谁”，结果可跳转。
- **批注**：在代码旁写一句话说明这段在路线里的作用，或者什么可以跳过。
- **全局切片库**：跨计划检索已有切片，同一个问题不必重新生成。
- **搜索面板**：直接搜阶段、骨架、切片、文件、函数。
- **多轨道**：同一个项目可以有多条学习轨道（例如“跑通主流程”和“只看数据层”），计划、切片、对话各自独立。
- **改动提示**：源码变了之后，切片会报告 moved / changed / missing，而不是静默显示旧内容。

## 支持的语言

| 语言 | 开箱可用 | 说明 |
| --- | --- | --- |
| Python | 是 | 应用内置 Python 语言服务器 |
| Java | 勾选下载 | 设置 → 语言服务器里勾选，下载 jdtls + 内置 JRE（约 100 MB），装完不依赖本机 Java |
| C / C++ | 勾选下载 | 同上，下载 clangd（约 30 MB），单个可执行文件，无额外运行时 |
| TypeScript / JavaScript | 需本机已装 | 系统 PATH 中要有 `typescript-language-server` |
| Go | 需本机已装 | 系统 PATH 中要有 `gopls` |

Java 和 C/C++ 的语言服务器体积较大，所以没有打进安装包：在 **设置 → 语言服务器** 里勾选后按需下载，安装包本身仍然是 38 MB 左右。下载可以后台进行，装完重新打开项目即可重建索引。

缺少某个语言服务器时，该语言的文件仍可正常浏览和阅读，只是不会生成符号与调用图。设置里也可以手动填写语言服务器的命令。

## 下载与安装（Windows）

| 版本 | 下载 | 说明 |
| --- | --- | --- |
| 安装版 | [Quick-TakeApart_2.1.0_x64-setup.exe](desktop/dist/Quick-TakeApart_2.1.0_x64-setup.exe) | 装到当前用户目录，不需要管理员权限，装完从桌面或开始菜单打开 |
| 便携版 | [Quick-TakeApart_2.1.0_x64-portable.zip](desktop/dist/Quick-TakeApart_2.1.0_x64-portable.zip) | 解压到任意目录，运行里面的 `Quick-TakeApart.exe`；删掉整个文件夹就等于卸载 |

安装包只包含 Python 阅读所需的部分，Java 与 C/C++ 的语言包在应用内按需下载（见上一节）。

不需要另外安装 Python、Node 或浏览器；系统需要 Windows 10/11 和 WebView2（一般自带，缺失时安装包会引导补装）。首次启动会先起本地引擎，窗口出现前有 1–3 秒等待。

界面只访问本机 `127.0.0.1`，不监听外网。

## 第一次用

1. **打开项目**：输入路径、点“选择文件夹”、在应用内逐级浏览，或从文件管理器把文件夹拖进窗口。
2. **等索引**：打开项目时会按实际用到的语言解析一遍符号，大项目需要几分钟；同一会话内后续操作都基于这次索引，不会反复解析。
3. **看骨架**：先确认主流程是否符合你的理解，再点节点看讲解。
4. **排计划**：把想读的部分拉成有序步骤，或让计划对话直接生成。
5. **进切片**：按顺序读，遇到问题就在右栏追问。

## 模型配置（可选）

骨架、节点讲解、计划和问答需要模型；纯代码阅读不需要。右上角 **设置 → API**：

- 服务商从内置目录里选，选中后默认 Base URL 与默认模型自动填好；
- 一份配置可以勾选多个模型，切换档案和模型只需一次操作；
- API Key 只进不出：保存后界面只能看到“已保存”和掩码，读不回来；
- “保存并拉取清单”会拉取该服务商可用的模型列表；拉不到时会用人话说明，模型名仍可手填；
- “探活”会真实发一次小请求，确认 key 与模型真的可用，不会把清单里没有的模型误判成写错。

不配置模型也能用：

- 骨架与切片退化为本地启发式结果，界面上标注“本地推测”；
- 节点讲解退化为符号清单式说明，不会编造完整逻辑；
- 计划对话会明确失败，而不是给一份假计划；
- 代码阅读、Ctrl+点击、文件导航、引用、切片复读完全不受影响。

## 数据放在哪里

- 项目的生成物（轨道、计划、切片、骨架、对话）都在该项目目录下的 `.qta/`，源码文件不会被写入或改动。
- 模型档案与密钥放在用户目录下的 `.qta/`，密钥单独存放。
- 下载的语言包放在用户目录下的 `.qta/langpacks/`，删掉只影响对应语言的索引能力。
- 想彻底清掉某个项目的所有生成结果，删掉该项目的 `.qta/` 目录即可，源码不受影响。

## 模型的隐私边界

模型不会拿到整个项目的源码。每次只发送按任务裁剪过的符号与调用清单，必要时再加一小段真实代码：

| 任务 | 发给模型 | 不发送 |
| --- | --- | --- |
| 逻辑骨架 | 全项目压缩符号表 | 源码正文 |
| 切片生成 | 以问题或选区为种子的聚焦符号表（带行号） | 全项目符号表、源码正文 |
| 节点讲解 | 节点符号 + 一跳邻居 + 节点附近代码窗口 | 全项目源码 |
| 侧页问答 | 切片符号 + 一跳邻居 + 切片片段 | 全项目源码 |
| 计划对话 | 当前计划 + 切片库元数据 | 源码、全量符号表 |

## 常见问题

**只看到文件，没有骨架和调用图？**
这个项目用的语言缺少语言服务器。Python 开箱可用；Java 与 C/C++ 可以在设置里勾选下载；TypeScript / JS 和 Go 需要系统里已装对应服务器。装好重开项目即可。

**语言包下载失败或很慢？**
下载走系统网络，失败时会在设置页直接显示原因，重试即可，已经下完的文件不会重复拉取。Java 包约 100 MB（含内置运行时），C/C++ 约 30 MB；公司网络有限速时可能偏慢，换网络环境会明显更快。

**语言包装好了，为什么还是没索引到？**
索引只在打开项目时做一次。装完语言包后重新打开该项目，才会把新语言的文件纳入骨架与调用图。

**语言包删了会不会影响别的东西？**
不会。语言包只存在于用户目录下的 `.qta/langpacks`，删掉只是让对应语言回到“只浏览、无调用图”的状态，项目里的数据与源码都不受影响。

**首次索引很慢？**
索引是按语言的完整解析，几千个文件的项目几分钟属于正常。

**关掉窗口后后台还留着东西吗？**
不会，引擎随窗口一起退出。

**要换项目怎么办？**
回到工作区切换或重新打开另一个项目，每个项目保留自己的轨道和生成结果。

**界面显示“后端进程是旧版本”？**
说明还连着一个旧的引擎实例。关闭窗口后重新打开应用即可。
